# TUZAKI — Render'ga joylash

1. Fayllarni GitHub'ga yuklang: `server.js`, `package.json`, `index.html`, `README.md`.
2. render.com → New → **Web Service** → shu repo'ni tanlang.
3. Build Command: `npm install`, Start Command: `npm start`.
4. Deploy.

## Ishlatish
- Sayt ochilganda nom so'raladi (har safar; hech qayerga saqlanmaydi).
- Nom yozilgach, odam xonaga kiradi va boshqalarni eshitadi. Xonada eng ko'pi 10 kishi.
- "Mikrofonni yoqish" bosilsa, odam gapira oladi.
- Mikrofon uchun sayt HTTPS bo'lishi kerak (Render o'zi beradi).
